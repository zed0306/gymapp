# GymApp — фитнес-помощник в Telegram

Мини-приложение (Telegram Mini App) для тех, кто только начинает ходить в зал — и для тех, кто уже давно тренируется.

**Адрес мини-аппа:** https://zed0306.github.io/gymapp/

## Что умеет

- **Анкета при первом входе:** пол, возраст, рост, вес, цель (похудеть / поддерживать / набрать), опыт, образ жизни, дни тренировок, ограничения по здоровью (колени, спина, плечи).
- **Уровень подготовки:** новичок, средний или продвинутый — определяется по опыту, можно поменять в профиле.
- **Выбор тренажёров с иллюстрациями:** 31 тренажёр и снаряд, нарисованы в едином стиле (SVG), сгруппированы по зонам; быстрые наборы «Обычный зал», «Дома: гантели», «Ничего нет».
- **Персональная программа:** сплит под уровень и число дней (фулбади, верх/низ, жимы/тяги/ноги), упражнения только из тех тренажёров, что есть в зале. Нагружающие больные зоны упражнения исключаются. Любое упражнение можно заменить, если тренажёр занят.
- **Режим тренировки:** подходы с весом и повторами, таймер отдыха с вибрацией, рекорды, объём, история. Приложение подсказывает, когда прибавлять вес (+2,5 кг на верх, +5 кг на ноги), а когда сбавить.
- **КБЖУ под цель** и дневник питания: база популярных продуктов и ввод своих блюд.
- **Трекер воды:** 30 мл/кг в обычный день, 40 мл/кг в день тренировки, график за неделю.
- **Профиль:** ИМТ, график веса, редактирование данных и зала.
- **Бот @gyminiappbot:** кнопка запуска мини-аппа, напоминания о воде и тренировках (по часовому поясу пользователя), админ-панель: статистика, рассылка, выгрузка пользователей.

Данные хранятся в **Telegram CloudStorage** — у каждого пользователя свои, и они доступны с любого устройства. Сервер для мини-аппа не нужен.

## Откуда цифры

| Что | Как считается | Источник |
|---|---|---|
| Базовый обмен (BMR) | Миффлин — Сан Жеор: 10·вес + 6,25·рост − 5·возраст + 5 (муж.) / −161 (жен.) | [Mifflin et al., 1990](https://pubmed.ncbi.nlm.nih.gov/2305711/) |
| Расход за день (TDEE) | BMR × 1,2…1,725 по числу тренировок + 0…0,15 за активный образ жизни | стандартные коэффициенты активности |
| Калории под цель | похудение −20% (не ниже BMR), поддержание 0, набор +10% (новичкам +15%) | |
| Белок | 1,6–2,0 г/кг (при дефиците больше) | [ISSN Position Stand, 2017](https://pmc.ncbi.nlm.nih.gov/articles/PMC5477153/) |
| Жиры | 0,8–1,0 г/кг, но 20–35% калорий | |
| Углеводы | остаток калорий | |
| Вода | 30 мл/кг, в день тренировки 40 мл/кг (1,5–5 л) | |
| Тренировки | новичкам 8–12 повторов, 2–3 фулбади в неделю; прогрессия +2–10% | [ACSM, 2009](https://pubmed.ncbi.nlm.nih.gov/19204579/) |

## Структура

```
index.html            точка входа мини-аппа
css/style.css         стили (тёмная и светлая тема под Telegram)
js/app.js             интерфейс и навигация
js/calc.js            формулы: BMR, TDEE, КБЖУ, вода, ИМТ
js/program.js         генератор программы тренировок
js/storage.js         Telegram CloudStorage + localStorage
js/data/              тренажёры, упражнения, продукты
img/equipment/        иллюстрации тренажёров (SVG)
tools/                генератор иллюстраций: node tools/draw-equipment.mjs
bot/                  Telegram-бот на aiogram 3
tests/                тесты формул и генератора (node --test)
```

## Запуск

### 1. GitHub Pages (один раз)

Репозиторий → **Settings → Pages** → *Build and deployment* → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
Через минуту приложение откроется по адресу https://zed0306.github.io/gymapp/.

### 2. Бот

Бот **@gyminiappbot** уже настроен: кнопка «Открыть» слева от поля ввода запускает мини-апп, заданы команды и описание. Это работает без сервера.

Чтобы бот отвечал на /start, слал напоминания и открывал админку, его нужно запустить на компьютере или сервере, который работает 24/7:

```bash
cd bot
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN и ADMIN_IDS
python bot.py
```

GitHub Pages умеет только отдавать файлы, поэтому бот там работать не может, а мини-апп — может.

**Админ-панель:** команда `/admin` (или кнопка в /start) для ID из `ADMIN_IDS` — статистика (новые и активные пользователи, кто подключил напоминания, цели и уровни), рассылка любого сообщения всем пользователям с предпросмотром, список новых пользователей и выгрузка в CSV.

Премиум-эмодзи в сообщениях и на кнопках бота работают, если у владельца бота есть Telegram Premium.

**Совет:** в @BotFather → Bot Settings → Configure Mini App можно включить главный мини-апп — у бота появится большая кнопка «Открыть» в профиле.

### Локально

```bash
python3 -m http.server 8080   # открыть http://localhost:8080
npm test                      # тесты формул и генератора программ
```

## Иллюстрации тренажёров

Все 31 иллюстрация нарисованы кодом в `tools/draw-equipment.mjs` из общих деталей (рама, подушки, весовые стеки, блины, тросы), поэтому выглядят в одном стиле и одинаково хорошо смотрятся в тёмной и светлой теме. Чтобы перерисовать: `node tools/draw-equipment.mjs`.

> Приложение не заменяет врача и тренера. При болях, хронических заболеваниях и беременности — сначала консультация специалиста.
